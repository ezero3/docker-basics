# 🐳 Docker Basics

Un'introduzione pratica a **Docker**, pensata per chi muove i primi passi con la containerizzazione nel mondo della Data Science.

## 📖 Descrizione

Questo repository raccoglie appunti, esempi e esercizi pratici per imparare le basi di Docker, seguendo un approccio hands-on ispirato a un video tutorial su YouTube.

## 🎯 Obiettivi

- Comprendere cos'è Docker e perché è fondamentale nella Data Science
- Imparare i concetti chiave: immagini, container, volumi, network
- Scrivere i primi `Dockerfile`
- Utilizzare `docker compose` per orchestrare più servizi
- Acquisire dimestichezza con GitHub e il versioning del codice
